# SpendWise — deployment-ready package

## Deploy overview (Render + MongoDB Atlas)
This project uses a React/Vite frontend and an Express backend. The backend serves the built frontend, so deploy it as **one Render Web Service**.

1. Create a GitHub repository and upload these files (do not upload any `.env` file or real user data).
2. Create a free MongoDB Atlas cluster, create a database user, and copy the Node.js connection string. Replace `<password>` with the database user's password and add `/spendwise` before the query string if needed.
3. In MongoDB Atlas Network Access, allow Render to connect. For a quick demo, `0.0.0.0/0` is broad access; only use it with a strong database password and understand the risk. Prefer a narrower allowlist if your setup supports it.
4. In Render, choose **New + → Blueprint** and connect this GitHub repository. Render will read `render.yaml`.
5. In the service's Environment settings, set `MONGO_URI` to the Atlas connection string. `JWT_SECRET` is generated by the Blueprint. Add `OPENAI_API_KEY` only if you use the AI assistant; otherwise leave it blank.
6. Deploy. Open the generated `https://...onrender.com` URL. Check `https://YOUR-APP.onrender.com/api/health`; it should report MongoDB connected.
7. Test registration/login and add a test transaction. Open the same public URL on another device/browser.

## Important
- Render free web services can sleep after inactivity, so the first visit may take a little time to wake up.
- Do not use the local JSON fallback for shared online data. It is not a reliable persistent production database; connect MongoDB Atlas and verify `/api/health` reports MongoDB connected.
- This is a demo project, not a financial institution. Do not enter real bank credentials or sensitive financial information.
- Keep `.env`, database passwords, JWT secrets, and API keys private.
